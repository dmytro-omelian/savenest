# Preview status

SaveNest 0.11.0 is available as a [signed preview](https://github.com/dmytro-omelian/savenest/releases/tag/v0.11.0) for Apple Silicon and Intel. Full launch is not complete.

The [GitHub launch tracker](https://github.com/dmytro-omelian/savenest/issues/13) holds rollout evidence, dependencies, and outstanding work. Keep operational updates there so they do not drift between duplicate checklists.

The [preview acceptance checklist](preview-acceptance.md) covers the remaining installed-app migration, offline import/export, browser permissions, analytics network behavior, Intel runtime, and update checks. Automated or sample-data checks do not establish those results.

To help with the desktop app, start with [CONTRIBUTING.md](../CONTRIBUTING.md). Official distribution is covered in [maintainer notes](maintainers.md).
